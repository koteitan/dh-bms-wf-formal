## 差異の根

差異の大半は 3 つの根に集約される。

| 根 | 内容 | P |
|---|---|---|
| **B** | 符号化の媒体。論文はコードを自然数とし Cantor 対 $\pi$ で符号化するが、Lean は Kuratowski 対による遺伝的有限集合、すなわち $L_\omega$ の元とする | P-01, P-02, P-03, P-09 |
| **C** | $\mathrm{KP} \vdash$ の不在。論文の §10 は「$\mathrm{KP}$ が次を証明する」という構文的主張だが、Lean には証明体系が無いので「許容 $\theta$ に対する $L_\theta$ の中で」という意味論的主張で代用する | P-04, P-05, P-06, P-07, P-08, P-14 |
| **D** | 関数記号の不在。論文は $\Delta_0$-定義可能関数を項の位置に書くが、Lean は関係として書き、出力を量化する | P-10, P-12 |

P-13 はどの根にも属さない個別の差異である。P-11 は原文どおりに書けており、
証明の筋の差だけを記録している。
