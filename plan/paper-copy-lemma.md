# 論文ルートのコピー補題 (branch `paper-copy-lemma`)

## 目的

`lean/Bm4/Copy.lean` はコピー補題（定理 6.3）を単一の閉形式 (`ParForm` / `AncForm`) で証明し、
論文の 6 つの主張 (C1)–(C6) をその系として読み出している。閉形式は行 `k` に関する一本の帰納で
済むため、論文 §6.9 の辞書式順位による非循環性の議論を必要としない。

このブランチでは、同じ定理を**論文の道筋そのまま**で証明する。すなわち

- (C1)–(C6) を独立した述語として立て、
- 局所補題 6.4–6.10 を、論文が各補題に与えた仮定だけで証明し、
- 命題 6.11 の三段階の組み立てで循環なく閉じる。

閉形式には一切依存しない。

## 記号

- `p` = bad root、`m₀` = `p` の親行、`s` = ブロック長、`c = A.len - 1`
- `G = [0, p)`、`B_q` = 第 q コピー、`pos q j = p + q*s + j` = `D_j⁽ᑫ⁾` の位置、`P⁽ᑫ⁾ = pos q 0`
- `x ≺ₖ y` = `anc` (狭義 k-祖先)、`x ≼ₖ y` = `ancEq`

## 主張

| 主張 | 内容 |
|---|---|
| (C1)ₖ | `pos q i ≺ₖ pos q j ⟺ p+i ≺ᴬₖ p+j` (コピー内部) |
| (C2)ₖ | `E ≺ₖ pos q j ⟺ E ≺ᴬₖ p+j` (`E < p`、G からコピーへ) |
| (C3)ₖ | `k < m₀` のとき `pos (q-1) i ≺ₖ P⁽ᑫ⁾ ⟺ p+i ≺ᴬₖ c` (次のコピーの先頭への橋) |
| (C4) | `m₀ ≤ k`, `q > 0` のとき `P⁽ᑫ⁾` の k-祖先はすべて `G` に入る |
| (C5)ₖ | 非先頭列の直 k-親は `G` に行くか同じコピー内に留まる（前のコピーへ飛ばない） |
| (C6)ₖ | `pos a i ≺ₖ pos c' j ⟺ pos a i ≺ₖ pos (c'+1) j` (`a < c'`) |

## 組み立て (命題 6.11)

- 第 1 段階 `stage1`: `k < m₀` を昇順に (C1)ₖ → (C3)ₖ → (C5)ₖ → (C2)ₖ → (C6)ₖ。(C4) は使わない。
- 第 2 段階 `claim4`: (C4)。`m₀ = 0` なら補題 6.9、`m₀ > 0` なら第 1 段階の
  (C3)_{m₀-1}, (C6)_{m₀-1} から補題 6.10。
- 第 3 段階 `stage3`: 全行を昇順に (C1)ₖ → (C5)ₖ → (C2)ₖ → (C6)ₖ。`k < m₀` は第 1 段階、
  `m₀ ≤ k` は (C4) を境界仮定に使う。

論文の順位付け `(0,k,·) < (1,0,0) < (2,k,·)` が、この 2 本の強帰納法にそのまま対応する。

## 閉形式からの独立性

`Bm4/CopyPaper/` の全ファイルについて、コメントを除去した上で閉形式の識別子
(`ParForm`, `AncForm`, `CandForm`, `CandHyp`, `anc_tA_iff`, `parent_tA_iff'`,
`anc_tA_internal`, `anc_tA_copies`, `anc_tA_G`, `target_unchanged`, `C1`…`C6`, `cor_6_12` 等)
を grep してヒット 0 を確認した。使用しているのは `Bm4/Copy.lean` のうち `BadRoot` の設定部分
(`pos`, `s`, `Δ`, `Asc`, `tA`, `col_pos*`, `anc_tA_prefix`, `not_asc_of_ge`,
`val_c_le_of_cand_m`, `between_*` など、`ParForm` の定義より前にある宣言) だけである。

`#print axioms BM4.BadRoot.theorem_6_3` → `[propext, Classical.choice, Quot.sound]`。

## 論文との差分（作業中に判明した点）

いずれも論文の誤りではなく、位置による定式化のほうが情報を多く持つために不要になった箇所。

1. 補題 6.5: 論文は区間内部の親（補題 6.2）を使って「`P⁽ᑫ⁾` の親が `B_{q-1}` に入る」ことを言うが、
   位置表現では `between_prev_copy` から直接出る。
2. 補題 6.7 手順 9: 論文は `E < p` を仮定して書いているが、直親 `u` が必ず `u < p` に落ちるため
   `E` に制限は要らない。`E < p` が本当に必要なのは構造候補の一致（k=0 の場合）と
   最小元への還元だけ。
3. 補題 6.8 の通過性 (6.16): (C5)ₖ だけで出るので (C1)ₖ は不要。
