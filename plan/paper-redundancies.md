# 原文にあるが必要なかった部分

論文の議論のうち、形式化してみると使わずに済んだ箇所。**論文が誤っているわけではない。**
位置による定式化のほうが情報を多く持つ、あるいは他の補題が場合を吸収している、というだけ。

論文を短くしたいときの候補として記録する。

## §6（コピー補題）

論文の道筋どおりに (C1)〜(C6) を証明した結果（`lean/Bm4/CopyPaper/`）判明したもの。

### 補題 6.5（§6.4、(C3)ₖ）— 区間内部の親の一段

論文は区間内部の親（補題 6.2）を使って「P⁽ᑫ⁾ の親が B_{q−1} に入る」ことを言う。
位置で書くと、コピー q の先頭列の左隣は必ずコピー q−1 の中なので、この一段は要らない。

### 補題 6.7（§6.6、(C2)ₖ）の最終段 — `E ∈ G` の仮定

論文は「その後の親鎖は共通接頭部分 G 内にあり、補題 3.1 で一致する」を `E ∈ G` の下で述べる。
実際には `E` に制限は要らない。R⁽ᑫ⁾ の直親が必ず G に落ちる（(C5)ₖ と R⁽ᑫ⁾ の最小性、または
(C4)）ので、残りの鎖は自動的に G の中に入る。

`E ∈ G` が本当に必要なのは、構造的候補の一致（k = 0 の場合）と、最小元 R への還元だけ。

### 通過性 (6.16)（§6.7）— (C1)ₖ

論文は補題 6.8 の証明の冒頭で (6.16) を示すが、そこで (C1)ₖ は使わない。(C5)ₖ だけで出る。
(C1)ₖ が必要になるのはその後の尾部の移送のところだけ。

## §17（有限行反映）

### 定理 17.1 の複雑度計算 — n = 0 と n > 0 の場合分け

論文は n = 0（第 4 群が無いので Σ̂1 → padding で Σ̂2）と n > 0（Σ̂1 を Π̂2 経由で Π̂(n+1) に
上げる）を分けるが、どちらも Σ̂(n+2) に着く。一律 Σ̂(n+2) で通る。

## §21（停止性）

### 定理 21.1 の r = 0 の場合分け

論文は r = 0 を「親となる行がなく、非空配列の展開は最後の列を一つ削除する」として別扱いする。
形式化では命題 19.1（`descent`）が最初に「最後の列に親があるか」で分岐し、r = 0 なら必ず
「最後の列を削除する」枝に落ちる。つまり命題 19.1 が r について一様で、r = 0 の議論を内側に
吸収している。定理 21.1 側の場合分けは要らない。

## §5–§6（コピー補題の仮定）

### C-5. 親行 m₀ の行最大性

論文 §5 は「c の最大親行を m₀」と固定し、定理 6.3 をその m₀ について述べる。(C1)〜(C6) の
証明は行 m 内での親の最大性しか使わず、行の最大性は使わない。論文が m₀ の行最大性を使うのは
§7 の (7.3) だけである。

形式化の `BadRoot` は「p が c の m-親」だけを持つ。

### C-6. (C6) のコピー番号の上限

論文の (C6) は `0 ≤ a < b < N` で、`b+1 ≤ N` は `Ã = A[N]` に `B_{b+1}` が存在するための
条件である。コピーを無限個持つ配列で述べれば上限は要らない。`A[N]` はその接頭部分になる。

## §11（KP の公理スキーマ）

### C-7. 分出・収集の副条件の `x`

論文の副条件は「x, y が φ に自由に現れない」だが、真理に必要なのは **`y ∉ fv(φ)` だけ**。

- `x` は先頭で ∀ 束縛されるので、φ 中の自由な `x` は単なるパラメータであり無害。
- `y` は本当に必要。φ := ¬(j ∈ y) を取ると、前件「各 i∈x に対しパラメータ y の外の j が在る」
  は真、後件「∃y' ∀i∈x ∃j∈y' (j ∉ y')」は j∈y' ∧ j∉y' が矛盾なので x ≠ ∅ で偽。

集合帰納法の `i ∉ fv(φ)` は必要（`∀j (j = i → φ)` が代入 φ(i) であるため）。

形式化は論文に合わせて `x` の条件も課している。

### C-8. 全称閉包の認識に導出列は要らない

「d は e に ∀ を有限個かぶせたものである」を Δ₀ で言うのに、§8 の導出**列**（関数・定義域・
添字）は要らない。「d を含み『∀ を 1 個剥がす』で閉じた集合 s が存在する」で足りる。

```
AllsW h w e d :⟺ ∃ s ∈ h, d ∈ s ∧
  ∀ z ∈ s, z = e ∨ ∃ i ∈ w, ∃ z' ∈ s, z = ⟨4, ⟨i, z'⟩⟩
```

∀ を剥がすとランクが真に減るので鎖は必ず止まり、止まれるのは e だけ。健全性はランクに関する
整礎帰納法、完全性は鎖の有限集合（HF なので `L ω` の元）を渡すだけ。定義 3 行で済む。

同様に「d が文である」も新しい認識子を作らずに `∀ k ∈ ω, NotFreeW(k, d)` と書ける。ω による
有界全称なのでそのまま Δ₀。

## §20（初期ラベル）

### C-9. 補題 20.1 の `r ≥ 1`

論文は r ≥ 1 を仮定するが、r = 0 でも成立する。安定性の祖先条件 `∀ k < r, …` が空になり、
単調性は初期対 Λ < Θ から出る。

## §9（L 階層コード）

### C-10. 定義 9.1 条件 4 の `a ∈ U`

条件 4 は `D(ξ)` の定義域を `{⟨e,a⟩ : e ∈ ω, a ∈ U, DefInp_{H(ξ)}(e,a)}` としているが、`a ∈ U`
は内容としては冗長。`DefInp_{H(ξ)}(e,a)` が `a` を `H(ξ)` 値の有限列に強制し、補題 8.2 から
`a ∈ U` が自動的に従う。この連言は Δ₀ 化のための有界化にすぎない。

形式化では `isDefEnum_eq_defEnum` として明示し、`D(ξ)` が `U` の選び方に依らないことを示した。

## §13（真理述語）

### C-11. 補題 13.3 の外部宇宙版で取る集合

論文は「a とその値域を含む推移的集合」として `A = TC(ran(a) ∪ {ran(a)})` を取れと書くが、
階数初切片 `V_γ` で足りる。推移閉包は要らない。

### C-12. 定義 14.2 の `Form_{Σ̂j}(e)`

(14.1) は `Form_{Σ̂j}(e) ∧ Asn_M(e,a) ∧ Tr_{Σ̂j}(e,a) → Tr^M_{Σ̂j}(e,a)` と書くが、定義 13.4 が
`Tr_{Σ̂j}` 自身に `Form_{Σ̂j}(e)` の連言を持たせているので、(14.1) の `Form_{Σ̂j}(e)` は論理的に
冗長。形式化では論文どおり両方に置いてある。

## §12（交代ブロック階層）

### C-13. 定義 12.1 の「自由変数はブロック内の束縛変数と衝突しない」

`fv (∃~x ψ) = fv ψ \ ~x` と定義すれば、全体の自由変数はどのブロックとも交わらない。この条件は
自動的に満たされ、明示する必要は無い。定義 12.1 で本当に効いているのは「各ブロックの変数が
相異なる」の方だけ。
