# 迂回のメモ

論文どおりに形式化できず、こちらの都合で別の道を通った箇所。論文が悪いのではなく、Lean で
書くときの制約による。

主定理の主張自体は論文の語彙だけでできていて、ここに挙げた迂回はどれも証明の内側の話である。

## D-1. 補題 10.5(1) を「KP が証明する」ではなく `L θ` で

**論文**: 「KP は次を証明する」と述べ、任意の W ⊨ KP の内部で使えるようにしている。

**こちら**: 許容な θ に対する `L θ` について外部で証明している
（`satCode_exists_in_L`、`lean/Bm4/SetTheory/SatInL.lean`）。

**理由**: 「KP が証明する」を形式化するには KP の内部導出系（証明可能性述語）が要る。論文が
実際に使うのは W = Lθ の場合だけ（§13.2 の補題 13.2 の証明）なので、実質的な差は無い。

**直すか**: 直さない。得るものがない。

## D-2. 命題 22.1 の「最小コード」を選択公理で代用

**論文**: R-最小元を持たない集合から降下列を作るとき、各段階で「自然数コード最小の元」を選ぶ
ことで選択公理を避けている。

**こちら**: `Classical.choice` を使う（`wellFounded_iff_isEmpty_descending_chain` の内部）。

**理由**: `Arr r` は `(len, col : ℕ → ℕ → ℕ)` で、`col` は総関数なので自然数に符号化できない。
論文の「BM4 全体は集合である」という一段が、この表現では成り立たない。

**直すか**: 直すには `Arr` を有限データの表現に変えることになり、全体に波及する。直さない。

なお定理 21.1 のほうは論文自身が Choice を使うので、そこは忠実。

## D-3. `Arr r` を総関数で表す

**論文**: 有限行列。

**こちら**: `(len : ℕ, col : ℕ → ℕ → ℕ)`。`len` 以降の列は親も祖先も読まないので、表現の差で
しかない。補題 3.1（接頭部分の不変性）は、この表現では `anc_congr_iff`（位置 ≤ i で一致する
2 配列は i の祖先が一致）という一般化された形になる。

D-2 の符号化ができない原因でもある。

## D-4. Lévy 階層を浅く埋め込む

**論文**: 「この論理式は Δ₀ である」と構文で言う。

**こちら**: 述語 `Pred := (ZFSet → Prop) → (ℕ → ZFSet) → Prop` に対する性質
`Delta0Def` / `SigmaDef` / `PiDef` として書く（`lean/Bm4/SetTheory/Defin.lean`）。構文
（`Fm`）も別に持っていて、`lean/Bm4/SetTheory/Rel.lean` で両者を繋いでいる。

**理由**: 構文だけで押すと、複雑度の計算のたびに論理式を組み立てる作業が入る。浅い埋め込みは
その簿記を型検査に任せられる。

## D-5. `LabelSystem` による抽象化

**論文**: Part III の結果（許容順序数、◁ₖ、定理 17.1）を Part IV/V で直に使う。

**こちら**: `LabelSystem`（`lean/Bm4/Label.lean`）という界面を挟み、Part IV/V をそれに対して
証明し、Part III で実装 `bm4LabelSystem` を与えている。

**理由**: Part III が大きいので、Part I/II/IV/V を先に閉じられるようにした。合成した主定理は
論文と同じ。

## D-6. `satIn_kpAx` の付値制限

`L θ` が KP の各公理を満たすことを言うとき、付値が `L θ` に入ることを要求している。KP の公理は
文なので付値に依らず、論文も代入は M 上を回すので、実質的な差は無い。無条件形（付値が `L θ`
の外に出てよい形）は ZFC で決定不能（V=L の無矛盾性）なので避けられない。

## D-7. 旧経路のファイルが残っている

`AdmP.lean` / `AdmPOK.lean` / `TV.lean` / `StRel.lean` / `Blk.lean` / `Truth.lean` は論文と
違う道の実装だが、論文経路がその補助補題の上に建っているので消せない。主定理はこれらに依存
しない（旧経路の補題を `sorry` に差し替えても `terminates_unconditional` が `sorryAx` を
拾わないことで確認済み）。

## D-8. テスト専用のファイル

`lean/Bm4/Compute.lean`（`expandC`, `Mat`, `parseMat`, `showMat`）は論文に無い。定義 5.1 の
計算可能版で、外部実装と 58 例を突き合わせるためのもの。定理は一切使わない。

## D-9. 定義 14.2 / 15.4 の良ドメイン条件を含意の仮定に置いた

`plan/paper-corrections.md` A-2 のとおり、相対化 `Tr^M` / `St_k(ξ)^M` が意図どおりの意味を
持つには M が推移的で h, w（, ξ）を含む必要がある。形式化ではこれを

```lean
def TVBodyP (D h w) (j : ℕ) (M) : Prop :=
  M.IsTransitive → (∃ x, x ∈ M) → h ∈ M → w ∈ M → …
```

と**含意の仮定**に置いた。連言に置くと `TVqP` が (14.1) より強くなって論文と違い、外すと
`PiDef.relativize` の正しさ条件が満たせず Π̂q 式として書けない。含意にすると論文より弱く
なるが、意図している内容は同じで、適用先（M = L η）では条件が自動的に満たされる。

`RelKP` の M についても同じ扱い。

## D-10. 補題 16.2 の Skolem 関数

論文は `<_L`-最小の Skolem 関数を外部で固定することで選択公理を避け、可算**極限** γ₀ > ω から
始めて各段も可算極限に取る。形式化は `Classical.choose` で証人を選び、γ₀ = ω+1（極限でない）
から始め、各段にも極限性を要求しない。

`<_L` の最小元を取るには L の大域整列を作る必要があり、そこは形式化していない。
D-2（命題 22.1 の最小コード）と同じ性格の迂回。

## D-11. §12 の定義的拡大

論文は `Vars(e)`, `Body(e)` を Δ₀-定義可能な関数記号として加えた定義的拡大を用い、Σ̂q と ≺*q は
その拡大におけるものとし、最後に全ての関数記号を Δ₀ グラフで消去できると述べる。

形式化では拡大を作らず、コードを直に扱っている。論文が「定義的拡大を使ってよい」と言う部分の
正当化（消去可能性）は形式化していない。

## D-12. 備考 7.2 のコピー式の一致

こちらの「公開規則」`expandOfficial` は `expand` と同じ `tildeCol` を使う定義なので、定理が
示すのは末尾判定と最大行の一致 ((7.2), (7.3)) だけである。コピー式そのものの一致は定義で
仮定されている。原実装との一致は、別途 58 例の突き合わせで経験的に確認しているだけ。

## D-13. `Standard.lean` の `hr : 0 < r`

(7.2), (7.3), 備考 7.2 の形式化には論文に無い `0 < r` が付く。`Arr` の `col` が総関数なので
r = 0 でも「第 0 行」が存在してしまうことに起因する（D-3 の帰結）。

## D-14. `BF.Sig` / `BF.Pi` にブロック変数の相異性を入れられない

定義 12.1 は各ブロックの変数が相異なることを要求する。`Fm.lean` の `IsSigma` / `IsPi` には
この条件を入れたが、ブロック式のクラス `BF.Sig` / `BF.Pi` には入れられなかった。

理由: 算術化したコード認識子 `IsSigCodeW` は相異性を**意図的に検査しない**設計で（検査する版が
`IsSigCodeWD`）、`BFCode.lean` の `isSigPiCodeW_iff : IsSigCodeW … q e ↔ ∃ b, BF.Sig q b ∧ …`
の → 向きが相異性を供給できない。`BF.Sig` を狭めるとこの同値が偽になる。

代わりに `BF.NodupBlocks` を `BF.lean` に置き、`BF.Sig.isSigma` がそれを仮定として取る形に
した。論文の Σ̂q は `BF.Sig q b ∧ b.NodupBlocks` に対応する。主定理が使う経路
（`IsSigCodeWD`、`GoodAsnQ`）は相異性を要求しているので、忠実性は保たれている。

## D-15. `IsConsSeq`（§8.1 の Cons の内部版）

`SatCode.lean` の `IsConcatSeq`（§8.1 の Concat）は長さに `∃ m : ℕ` というメタレベルの量化を
含むため、そのままでは Δ₀ にできない。定義 9.1 の条件 4 は `a_x`（連結代入）を Δ₀ 述語の中で
使うので、ZF 内部の後続 `insert j j` で書き直した `IsConsSeq x a ax`（`ax(0) = x`,
`ax(j+1) = a(j)`）を別に用意した。補題 8.2 と接続してある。
