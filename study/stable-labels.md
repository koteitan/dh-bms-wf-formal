## 0. 第 I・II 部から使うもの

第 IV 部は組合せ論の言葉で書かれている。ここでは使う分だけを並べる。
証明は原文の第 I・II 部にある。

### 0.1 配列、親、祖先

$`r`$ 行、長さ $`\ell`$ の **配列** とは $`A = (A_0, \dots, A_{\ell-1}) \in (\mathbb{N}^r)^\ell`$ である。
$`A_i(k)`$ を第 $`i`$ 列の第 $`k`$ 成分と書く。位置集合を
$`\mathrm{Pos}(A) = \{0, \dots, \ell-1\}`$ とする。

**定義 2.1.** $`i \in \mathrm{Pos}(A)`$、$`k \lt r`$ とする。$`j \lt i`$ が $`i`$ の
**構造的 $`k`$-親候補** であるとは、$`k = 0`$ のときは単に $`j \lt i`$ であること、
$`k \gt 0`$ のときは $`j`$ が $`i`$ の狭義 $`(k-1)`$-祖先であることをいう。
さらに $`A_j(k) \lt A_i(k)`$ を満たす構造的候補を **有効候補** と呼ぶ。
有効候補のうち最大の列番号が存在すれば、それを $`i`$ の **$`k`$-親** とする。

$`j \prec^A_k i`$ とは、親を有限回たどって $`i`$ から $`j`$ へ達することをいう。
$`j \preceq^A_k i`$ は $`j = i`$ または $`j \prec^A_k i`$ である。

**補題 2.2 のうち使うもの.**

1. $`j \prec^A_k i`$ なら $`j \lt i`$ かつ $`A_j(k) \lt A_i(k)`$
2. $`h \lt k`$ かつ $`j \prec^A_k i`$ なら $`j \prec^A_h i`$
3. $`u, v`$ がともに $`w`$ の $`k`$-祖先で $`u \lt v`$ なら $`u \prec^A_k v`$

### 0.2 展開（定義 5.1）

$`\ell = 0`$ なら $`A[N] = A`$ とする。$`\ell \gt 0`$ とし、最後の列番号を $`c = \ell-1`$、
最後の列を $`C = A_c`$ とする。

$`c`$ がどの行にも親を持たなければ、$`A[N]`$ は $`C`$ を削除した接頭部分 $`A \restriction c`$ である。

$`c`$ が親を持つとき、その **最大親行** を $`m_0`$、$`c`$ の $`m_0`$-親を $`p`$、その列を
$`P = A_p`$ とする。

```math
G = (A_0, \dots, A_{p-1}), \qquad
B_0 = (A_p, \dots, A_{\ell-2}) = (D_0, \dots, D_{s-1})
```

ただし $`D_0 = P`$、$`s = \ell - 1 - p`$ である。$`p \prec^A_{m_0} c`$ なので
$`k \lt m_0`$ に対し $`\Delta_k = C(k) - P(k) \gt 0`$ である。

$`k \lt m_0`$ において $`D_j`$ が **上昇する** とは $`p \preceq^A_k (p+j)`$ が成り立つことをいう。
$`q = 0, \dots, N`$ に対しコピー $`B_q = (D_0^{(q)}, \dots, D_{s-1}^{(q)})`$ を

```math
D_j^{(q)}(k) =
\begin{cases}
D_j(k) + q\Delta_k & (k \lt m_0 \text{ かつ } D_j \text{ が上昇する}) \cr
D_j(k) & (\text{それ以外})
\end{cases}
```

で定め、$`A[N] = G \frown B_0 \frown \cdots \frown B_N`$ とする。この操作は行数 $`r`$ を変えない。

### 0.3 接頭部分の不変性（補題 3.1）

接頭部分 $`A \restriction m`$ に属する 2 つの位置について、$`k`$-親および $`k`$-祖先関係は、
接頭部分で計算しても全配列で計算しても同じである。

### 0.4 コピー補題（定理 6.3）

$`A[N]`$ における祖先関係を、元の配列 $`A`$ における関係で書き換える。第 IV 部が使うのは
次の 3 つと系 1 つである。上付きの無い $`\prec_k`$ は $`A[N]`$ での関係を表す。

```math
\text{(C1)} \qquad D_i^{(q)} \prec_k D_j^{(q)} \iff D_i^{(0)} \prec^A_k D_j^{(0)}
```
```math
\text{(C2)} \qquad E \in G \text{ について } E \prec_k D_j^{(q)} \iff E \prec^A_k D_j^{(0)}
```
```math
\text{(C6)} \qquad 0 \le a \lt b \lt N \text{ について }
D_i^{(a)} \prec_k D_j^{(b)} \iff D_i^{(a)} \prec_k D_j^{(b+1)}
```

**系 6.12（隣接コピーを横切る祖先）.** $`D_i^{(q)} \prec_k D_j^{(q+1)}`$ なら

```math
k \lt m_0, \qquad D_i^{(0)} \prec^A_k C, \qquad P \preceq^A_k D_j^{(0)} . \tag{6.24}
```

## 1. 安定ラベル（定義 18.1）

**定義.** $`A`$ を $`r`$ 行、長さ $`\ell`$ の配列とする。**安定ラベル** とは、列の出現位置を
定義域とする関数

```math
f : \{0, \dots, \ell-1\} \longrightarrow \mathrm{Ord}
```

で、次の 3 条件を満たすものをいう。

1. 各 $`f(i)`$ は許容順序数である
2. $`i \lt j`$ なら $`f(i) \lt f(j)`$ である
3. $`i \prec^A_k j`$ なら $`f(i) \lhd_k f(j)`$ である

空配列には空関数を割り当てる。

**意味.** 配列の各列位置に許容順序数を貼り、位置の順序と親子関係を、
順序数の大小と安定関係 $`\lhd_k`$ に翻訳する。条件 3 が第 III 部との接続点である。

同じ列ベクトルが 2 つの位置に現れても、その 2 位置は別々のラベルを持つ。
だから $`f(C)`$ のような書き方はせず、常に列位置でラベルを指定する。

## 2. 高さ

**定義.** $`A`$ が非空なら

```math
\mathrm{ht}(f) = f(\ell-1)
```

を $`f`$ の **高さ** と呼ぶ。最後の列位置のラベルである。

条件 2 から、高さは $`f`$ の値の中で最大である。

## 3. 命題 19.1（高さ下降）

### 3.1 主張

非空な固定 $`r`$ 行配列 $`A`$ が安定ラベル $`f`$ を持つとする。任意の $`N \in \mathbb{N}`$ について、
$`A[N]`$ が非空なら安定ラベル $`g`$ を持ち

```math
\mathrm{ht}(g) \lt \mathrm{ht}(f) . \tag{19.1}
```

すなわち、定義 5.1 の一回の展開は安定ラベルの高さを厳密に下げる。

以下 $`c = \ell-1`$、$`C = A_c`$、$`\beta = f(c) = \mathrm{ht}(f)`$ と置く。

### 3.2 場合 1：C がどの行にも親を持たない

このとき $`A[N] = A \restriction c`$ である。補題 3.1 により接頭部分に残る親・祖先関係は
元の $`A`$ と同じなので、$`f \restriction c`$ は安定ラベルである。接頭部分が非空なら
その最後の位置は $`c`$ より小さいため、条件 2 から高さは $`f(c) = \beta`$ より小さい。

### 3.3 場合 2：設定

最大親行 $`m_0`$ が存在するとする。0.2 の記号を使い、位置によるラベルを

```math
\alpha = f(p), \qquad y_i = f(p+i) \quad (0 \le i \lt s)
```

と置く。$`p \lt p+1 \lt \cdots \lt p+s-1 \lt c`$ と条件 2 から

```math
\alpha = y_0 \lt y_1 \lt \cdots \lt y_{s-1} \lt \beta . \tag{19.2}
```

また $`p \prec^A_{m_0} c`$ だから条件 3 より

```math
\alpha \lhd_{m_0} \beta . \tag{19.3}
```

これが定理 17.1 の仮定にあたる。

### 3.4 帰納構成

$`q = 0, \dots, N`$ に対し

```math
A_q = G \frown B_0 \frown \cdots \frown B_q
```

と置く。これは展開パラメータを $`q`$ とした定義 5.1 の展開そのもので、$`A_q`$ は
$`A_{q+1}`$ の接頭部分である。$`A_q`$ 上の安定ラベル $`f_q`$ を、次の 2 つの不変量を
満たすように構成する。

| | 不変量 |
|---|---|
| (I1) | 最後のコピー $`B_q`$ の第 $`i`$ 列のラベルは $`y_i`$ である |
| (I2) | $`B_q`$ より前にある全ての列のラベルは $`\alpha`$ より小さい |

**$`q = 0`$.** $`A_0 = A \restriction c`$ である。補題 3.1 により $`f_0 = f \restriction c`$ は
安定ラベルである。$`B_0`$ のラベルは定義どおり $`y_i`$ であり、$`G`$ は位置 $`p`$ より前に
あるため、条件 2 からその全ラベルは $`f(p) = \alpha`$ より小さい。

**$`q`$ から $`q+1`$.** $`B_q`$ より前に現れるラベルの集合を

```math
X = \{\, f_q(u) : u \text{ は } B_q \text{ より前の位置} \,\}
```

とする。これは許容順序数からなる有限集合であり、(I2) から $`X \subseteq \alpha`$ である。また

```math
Y = \{y_0 \lt \cdots \lt y_{s-1}\} \subseteq [\alpha, \beta)
```

は許容順序数からなる非空有限集合である。$`m_0 \lt r`$ と (19.3) により、定理 17.1 を

```math
n = m_0, \qquad (\alpha, \beta, X, Y)
```

へ適用できる。その結果、許容順序数 $`y'_0, \dots, y'_{s-1}`$ で

```math
y'_0 \lt \cdots \lt y'_{s-1} \lt \alpha \tag{19.4}
```

かつ

```math
\max(X \cup \{\omega\}) \lt y'_0 \tag{19.5}
```

を満たし、さらに (17.2)–(17.4) を満たすものが得られる。$`A_{q+1}`$ 上の関数 $`f_{q+1}`$ を
次のように定める。

1. $`B_q`$ より前では $`f_q`$ と同じ値を保つ
2. $`B_q`$ の第 $`i`$ 列のラベルを $`y_i`$ から $`y'_i`$ へ変更する
3. 新しい $`B_{q+1}`$ の第 $`i`$ 列へ元の値 $`y_i`$ を割り当てる

**押し下げて空けた場所に、元の値をそのまま置き直す** のがこの構成である。

### 3.5 狭義増加性

条件 2 を確認する。

| 区間 | 根拠 |
|---|---|
| $`B_q`$ より前の最後 $`\to`$ $`B_q`$ の先頭 | (19.5) により $`\max X \lt y'_0`$ |
| $`B_q`$ の内部 | (19.4) の $`y'_0 \lt \cdots \lt y'_{s-1}`$ |
| $`B_q`$ の末尾 $`\to`$ $`B_{q+1}`$ の先頭 | (19.4) の $`y'_{s-1} \lt \alpha`$ と $`\alpha = y_0`$ |
| $`B_{q+1}`$ の内部 | (19.2) の $`y_0 \lt \cdots \lt y_{s-1}`$ |

全体で狭義増加する。新しい最後のコピーは $`y_i`$ を持つので (I1) が成立し、
それ以前のラベルは全て $`\alpha`$ 未満なので (I2) も成立する。

### 3.6 祖先条件の 6 場合

残るのは条件 3 である。祖先は必ず対象列より左にある。対象列と祖先の位置で場合分けすると、
次の 6 つで尽きる。

| | 祖先の位置 | 対象列の位置 | 使う結果 |
|---|---|---|---|
| (a) | $`A_q`$ 内 | $`B_q`$ より前 | 補題 3.1 |
| (b) | $`A_q`$ 内 | 旧最後コピー $`B_q`$ | (17.2), (17.3) |
| (c) | 新 $`B_{q+1}`$ | 新 $`B_{q+1}`$ | (C1) |
| (d) | $`G`$ | 新 $`B_{q+1}`$ | (C2) |
| (e) | $`B_a`$（$`a \lt q`$） | 新 $`B_{q+1}`$ | (C6) と補題 3.1 |
| (f) | 旧最後コピー $`B_q`$ | 新 $`B_{q+1}`$ | 系 6.12 |

**(a).** 対象列とその祖先はともに接頭部分 $`A_q`$ のうち $`B_q`$ より前にある。
$`A_q`$ は $`A_{q+1}`$ の接頭部分なので補題 3.1 により祖先関係は変化せず、ラベルも変更していない。
$`f_q`$ の安定性がそのまま使える。

**(b).** 対象を $`D_j^{(q)}`$ とする。対象とその全ての祖先は $`A_q`$ に属するので、
補題 3.1 により $`A_{q+1}`$ における祖先関係は $`A_q`$ におけるものと同一である。

- 祖先が $`B_q`$ より前にあり、その現在のラベルを $`x \in X`$ とすれば、$`f_q`$ の安定性から
  $`x \lhd_k y_j`$。これが (17.2) により $`x \lhd_k y'_j`$ へ保存される
- 祖先も $`B_q`$ 内の $`D_i^{(q)}`$ なら、変更前の安定性から $`y_i \lhd_k y_j`$。
  (17.3) により $`y'_i \lhd_k y'_j`$

**(c).** $`D_i^{(q+1)} \prec_k D_j^{(q+1)}`$ とする。(C1) を全コピー数 $`q+1`$ の配列 $`A_{q+1}`$ に
適用すると $`D_i^{(0)} \prec^A_k D_j^{(0)}`$。元の安定ラベル $`f`$ から $`y_i \lhd_k y_j`$ で、
新しいコピーのラベルは $`y_i, y_j`$ なので必要な関係を得る。

**(d).** $`E \in G`$ と $`E \prec_k D_j^{(q+1)}`$ を取る。(C2) から $`E \prec^A_k D_j^{(0)}`$。
$`G`$ のラベルと新しいコピーのラベルは元の $`f`$ と同じなので、元の安定性をそのまま適用できる。

**(e).** $`D_i^{(a)} \prec_k D_j^{(q+1)}`$ とする。(C6) を全コピー数 $`q+1`$、$`b = q`$ として
適用すると $`D_i^{(a)} \prec_k D_j^{(q)}`$。両列は接頭部分 $`A_q`$ に属するので、
補題 3.1 によりこれは $`A_q`$ での関係と同値である。$`f_q`$ の安定性を適用し、
祖先の現在ラベルを $`z`$ とすれば $`z \lhd_k y_j`$ を得る。$`B_a`$ のラベルはこの段階で
変更せず、新対象のラベルも $`y_j`$ なので必要な関係が成立する。

**(f).** $`D_i^{(q)} \prec_k D_j^{(q+1)}`$ とする。系 6.12 から

```math
k \lt m_0, \qquad D_i^{(0)} \prec^A_k C, \qquad P \preceq^A_k D_j^{(0)} . \tag{19.10}
```

最初の祖先関係と元の $`f`$ の安定性から

```math
y_i \lhd_k \beta . \tag{19.11}
```

$`k \lt m_0 = n`$ なので、定理 17.1 の (17.4) を (19.11) へ適用して

```math
y'_i \lhd_k \alpha . \tag{19.12}
```

- $`j = 0`$ なら新対象のラベルは $`y_0 = \alpha`$ であり、(19.12) が必要な関係そのものである
- $`j \gt 0`$ なら $`P`$ と $`D_j^{(0)}`$ は異なる位置なので、(19.10) の最後の非狭義関係は狭義である。
  元の安定性から $`\alpha \lhd_k y_j`$。これと (19.12) を補題 15.1(2) の推移性でつなぎ
  $`y'_i \lhd_k y_j`$ を得る

以上 6 場合で $`f_{q+1}`$ が安定ラベルであることが示された。

### 3.7 結論

$`q`$ に関する有限帰納法により $`f_N`$ を得る。最後のコピー $`B_N`$ のラベルは
(I1) により常に $`y_0, \dots, y_{s-1}`$ なので、(19.2) から

```math
\mathrm{ht}(f_N) = y_{s-1} \lt \beta = \mathrm{ht}(f) .
```

$`\square`$
